# Technical design

Documentation-only workflow extension, no new executable deploy or state validator. Canonical .agents/docs/production-lifecycle.md owns state/evidence/authorization/recovery rules. Existing skills route to its relevant section only for selected release/operations scope. Templates live in .specify/templates/operations-template.md and release-template.md; copy only when missing, otherwise patch confirmed sections without clobbering custom content. Product CI/CD stays project-specific and only configured after actual manifests/hosting/commands are established. Existing updater already protects docs/ and source-removed files; extend integration fixtures, not deletion logic. Manual scenario matrix evaluates lifecycle decisions and independent review checks fidelity; source tests enforce route/template/preservation contracts, not pretend live deployment.
