# Lean dev-to-production lifecycle

Status: SIGNED-OFF v1.0

Owner approved the preceding proposal: lightweight release flow reusing existing skills, a stable OPERATIONS guide and one short release record per version. Implement framework rules/templates and synchronization; verify preservation. No real product deployment, cloud/CI platform choice, new skill, dependency/runtime or Git mutation is authorized or needed.

Reuse BA-first Fast/Full gates. Feature completion, release readiness and production verification are separate. Apply production checks per release/risk, not every task. Reuse current evidence bound to the candidate and target environment. Operations documentation preserves custom content and secrets are names/references only. Gate applicable required failures/missing evidence; Critical risk cannot be accepted. Production writes require matching explicit authorization already in force, without repeated confirmation. Existing updater zero-deletion behavior and immutable history remain.
