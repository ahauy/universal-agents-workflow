# Workflow registration retirement

The upstream GitHub Spec Kit executable workflow and registration are retired.
UAW is file-based: AGENTS.md selects the lane; native cold skills technical-spec,
implementation-plan, task-breakdown and technical-consistency-review provide
Full-lane planning after a signed-off BA baseline. No workflow engine is needed.

Legacy speckit-* paths are migration stubs. Existing projects may retain local
customizations; do not delete or overwrite modified customer files. This source
retirement does not authorize running retained upstream YAML or hooks.
