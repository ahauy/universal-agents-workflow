# command-update — Smart Update Skill

## Purpose

Safely update the Universal Agents Workflow framework to the latest version
**without losing any project data or user customizations**.

---

## Trigger Examples

```
/update
/upgrade
check update
cập nhật framework
có bản cập nhật không
```

---

## What Is Protected (NEVER Overwritten)

These files and directories are **absolutely protected** — the update engine
skips them entirely regardless of any other logic:

| Protected Path                        | Why                                                  |
| ------------------------------------- | ---------------------------------------------------- |
| `CONTEXT.md`                          | Project ubiquitous language                          |
| `PRODUCT_BACKLOG_ROADMAP.md`          | Product backlog & roadmap                            |
| `CHANGELOG.md`                        | Project change history                               |
| `UPGRADE_NOTICE.md`                   | Update guidance file                                 |
| `adr/` (except `adr/adr-template.md`) | Architecture Decision Records                        |
| `docs/features/`                      | Tech docs generated by tech-doc-architect            |
| `docs/user-guides/`                   | User guides with Playwright screenshots              |
| `docs/architecture/`                  | Architecture documentation                           |
| `docs/RUN_AND_TEST.md`                | Project-specific run & test guide                    |
| `.specify/features/`                  | All BA pipeline output (specs, test plans, baseline) |
| `src/`                                | Project source code                                  |
| `.env`, `.env.*`                      | Environment variables & secrets                      |
| `*.local`, `*.local.md`               | Machine-local configuration                          |

Additionally, any file the user **added to `.agents/`** that was not part of the
original framework installation is preserved (**Zero Deletion Policy**).

---

## Update Behaviour by File Type

| File Type                                 | Action                                                     |
| ----------------------------------------- | ---------------------------------------------------------- |
| Protected path                            | 🛡️ Skip entirely — never touched                           |
| User-added custom skill/agent             | 👤 Retained — never deleted                                |
| Framework file (unmodified since install) | ✅ Auto-updated silently                                   |
| Framework file (user has modified it)     | ⚠️ Ask: `[K]eep / [O]verwrite (.bak) / [D]iff (.upstream)` |

---

## Execution Steps

When the user triggers `/update`:

1. **Read `protectedPaths`** from `.agents/workflow-source.json` (Step 0 — immutable gate).
2. **Check remote version** from `version.json` on GitHub.
   - If offline → log `[OFFLINE - skipped version check]` and exit gracefully.
   - If already up-to-date → inform user and stop.
3. **Run the update engine script**:
   ```bash
   python3 .agents/scripts/update-engine.py --apply --target .
   ```
4. **Display the summary report** with 4 groups:
   ```
   ✅ Updated:              N files
   🛡️ Protected (skipped):  N paths
   👤 User-Custom Retained: N files
   ⚠️ Conflicts Resolved:   N files
   ```
5. **Update `workflow-source.json`** with new version and rebuilt manifest checksums.

## Manual CLI Alternative

Users who do not have an AI Editor can update via:

```bash
# Option 1: re-run installer with --update flag
curl -fsSL https://raw.githubusercontent.com/ahauy/universal-agents-workflow/main/install.sh | bash -s -- --update

# Option 2: run the engine directly inside the project
python3 .agents/scripts/update-engine.py --apply

# Option 3: check only (no changes made)
python3 .agents/scripts/update-engine.py --check
```

---

## Offline Behaviour

If there is no network access:

- `--check` mode: silently logs `[OFFLINE]` and exits with code 0.
- `--apply` mode: prints a clear message and exits without modifying any files.
- **No crash. No data loss. No error spam.**

---

## Conflict Resolution Options

When a framework file has been locally modified:

| Option          | Effect                                                        |
| --------------- | ------------------------------------------------------------- |
| **[K]eep**      | Keep your version. Upstream change is discarded.              |
| **[O]verwrite** | Apply new version. Your version is saved as `<file>.bak`.     |
| **[D]iff**      | New version saved as `<file>.upstream` for manual comparison. |
