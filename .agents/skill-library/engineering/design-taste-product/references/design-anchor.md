## 5. Design anchor (`DESIGN.md`)

Use the shared [design anchor contract and template](../../design-taste-frontend/references/shared-design-foundations.md#design-anchor). It owns palette, type roles/scale/weights, spacing, radius, shadow, motion and reference notes for both product and marketing screens. Do not keep a second template here.

For product screens, record existing app conventions and semantic states only when required by confirmed domain behavior. Every new dashboard, form and management screen reuses this anchor. Preserve custom token notes and update agreed decisions in place only when the owner changes direction; never regenerate the file because a new screen needs a different layout.
